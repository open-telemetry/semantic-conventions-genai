Merge `gen_ai.invoke_workflow.internal` into `gen_ai.invoke_agent.internal` and `gen_ai.invoke_workflow.duration` into `gen_ai.invoke_agent.duration`; `gen_ai.operation.name` tells agent, workflow, and framework entrypoint invocations apart. Remove `gen_ai.workflow.name`: workflow invocations record their name in `gen_ai.agent.name`. Framework entrypoints that are not themselves an agent or a workflow use an `invoke_{framework_entrypoint}` operation name instead of `invoke_workflow`, for example `invoke_runner` for ADK and OpenAI Agents `Runner.run(...)`. `gen_ai.operation.name` is now required on `gen_ai.invoke_agent.duration`, `gen_ai.invoke_agent.inference_calls`, and `gen_ai.invoke_agent.tool_calls`, and `gen_ai.agent.name` is conditionally required on the latter two. The low-cardinality guidance for `gen_ai.agent.name` (no instrumentation-time constants, framework defaults, or type names; not captured by default when no meaningful name is available) now applies wherever the attribute is used.
